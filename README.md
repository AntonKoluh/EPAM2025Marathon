# 🎅 Saint Nick's Gift Exchange

My take on EPAM Marathon 2025 idea, all code was written by me.

---

## 🎁 Extra Features
- AI integration: If your giftee is unsure of what he/she wants, and provided only a list of preferences, AI can provide you with 5 idea, including links to the product that will fit the budget!
- Removal of users from room by administrator
- Admin link recovery (Sometimes we forget to save links, oops!)
- Join room by link or by code

---

## 🛠️ TechStack:
frontend - React, shadcn, tailwind css <br>
Backend - Django restful API <br>
AWS - backend on AWS E2C using nginx, frontend on AWS Amplify <br>
